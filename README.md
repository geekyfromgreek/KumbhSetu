# 🕉️ KumbhSetu 2026: Maha Kumbh Mela Ecosystem

Welcome to the **KumbhSetu 2026** codebase. This repository contains the unified multi-app ecosystem developed for the **Maha Kumbh Mela 2026 (Nashik–Trimbakeshwar)**.

---

## 📂 Repository Structure

- 📱 **[`KumbhSetu-Expo`](file:///d:/t3-kumbhsetu/KumbhSetu-Expo)**: Main Mobile Application for Yatris and Pilgrims.
- 🏛️ **[`KumbhSetu-Admins`](file:///d:/t3-kumbhsetu/KumbhSetu-Admins)**: Administration, RTO, and Municipal Corporation Regulatory Portal.
- 🏪 **[`KumbhSetu-LocalBazaar`](file:///d:/t3-kumbhsetu/KumbhSetu-LocalBazaar)**: Local Merchant, Stall, and Eatery Management App.
- 🤝 **[`KumbhVeer`](file:///d:/t3-kumbhsetu/KumbhVeer)**: Ground Volunteer, Safety Patrol, and Fact-Checking App (English & मराठी).
- 🗄️ **[`supabase_schema.sql`](file:///d:/t3-kumbhsetu/supabase_schema.sql)**: Unified SQL schema, triggers, and realtime publications for Supabase.
- 📖 **[`KUMBHSETU_DOCUMENTATION.md`](file:///d:/t3-kumbhsetu/KUMBHSETU_DOCUMENTATION.md)**: Comprehensive technical documentation, architecture, and feature guide.

---

## ⚡ Quick Start

```bash
# 1. Pilgrim App
cd KumbhSetu-Expo && npx expo start

# 2. Admin Portal
cd KumbhSetu-Admins && npx expo start

# 3. Local Bazaar App
cd KumbhSetu-LocalBazaar && npx expo start

# 4. Volunteer App
cd KumbhVeer && npx expo start
```

For complete technical documentation, please view **[KUMBHSETU_DOCUMENTATION.md](file:///d:/t3-kumbhsetu/KUMBHSETU_DOCUMENTATION.md)**.
